Media Library Organizer

Background:
You're building a system to organize and manage a digital media library consisting of photos and videos.

The system needs to handle:
- File organization
- Metadata extraction
- Metadata storage
- Smart searching

Each file in the system contains the following metadata:

 - file_path: str
 - Example: "vacations/beach/IMG_001.jpg"

 - file_type: str
 - Example: "image/jpeg" or "video/mp4"

 - size_bytes: int

 - created_at: datetime

 - metadata: dict
 - Example:
    {
        "resolution": "1920x1080",
        "duration": "00:02:30"
    }

 - tags: list[str]
 - User-defined tags used for categorization and search.


Part 1: File Organization

Implement a MediaLibrary class that:
- Organizes files into a virtual folder structure
- Supports adding and removing files
- Allows moving files between folders
- Maintains unique file paths
- Validates file types (only allow image/* and video/*)
